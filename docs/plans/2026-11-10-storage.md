# CS336 Storage Implementation Plan

Goal: Separate code, versioned datasets and per-run artifacts on WSL and mentor-gpu.
Architecture: Preserve assignment layout; use user-home defaults with environment overrides and compatibility symlinks. Transfer using SSH and a user-local rsync; never delete destination files automatically.
Tech stack: Python standard library, Bash, rsync, SSH.

1. Snapshot affected source and old artifact inventories; check for active training.
2. Move a1 data and checkpoints to external versioned/legacy directories with SHA-256 verification. Preserve compatibility symlinks and archive old root-level artifacts.
3. Track experiment scripts/configuration/docs via selective gitignore. Update A1 path defaults and suite configuration; preserve existing training math.
4. Record code revisions, working-tree changes and data hashes. Store suite manifest paths relative to the suite, supporting legacy absolute manifests.
5. Add code/data upload and result-download helpers with dry-run, exclusions and backup of overwritten destination files.
6. Test path resolution, portable summaries, sync dry-runs and content identity; upload changes and data to mentor-gpu. Do not start training or publish commits.
